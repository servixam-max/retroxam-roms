# TICO-Roms — catálogo filtrado

Subconjunto del catálogo de AndroidRoms limitado a la biblioteca curada de la consola:
solo los juegos que ya están en los gamelists de ES-DE (lo mejor de cada sistema).

36 sistemas · 5.496 entradas. Formato JSONL, uno por sistema, compatible con GitHubRoms.

## Documentación del proyecto

- **[docs/CONTINUAR.md](docs/CONTINUAR.md)** — punto de entrada para retomar el proyecto: entorno, dispositivo, trampas resueltas, estado real y próximos pasos.
- [docs/TAREAS.md](docs/TAREAS.md) — backlog vigente (tabla `## Tareas`).
- [docs/ESTADO.md](docs/ESTADO.md) — bitácora cronológica completa.
- `docs/ESTADO-LOG.html` / `docs/TAREAS-LOG.html` — las mismas bitácoras en HTML con índice navegable.
- [tools/](tools/) — scripts de validación del catálogo, comparación con los gamelists y guardas de memoria del dispositivo.
